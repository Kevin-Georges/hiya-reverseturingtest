# AI tools used
## Claude web chat interface

I used claude sonnet to brainstorm ideas for the project, going back and forth until I found something I was happy with. I used sonnet since I did not need a lot of reasoning, just something I could talk to so that I could figure out what type of project I wanted to build.

After the initial prototype I went back to the web interface and started chatting with sonnet to design features or additions to the program to improve it.

## Claude Code: Code Review

I then set up my terminal with the Feature Dev plugin to help with structured planning and architecture. I used Opus 5.5 with high effort when scaffolding and making decisions, and kept it the same for the building. 

Once I built the initial prototype I used the Code Review plugin to find any bugs or mistakes with my code, and then gave 2 agents a task of building tests for my code and to run them. I iterated on this continuing to test and fix until I was satisfied, I then did the same to add new features.
